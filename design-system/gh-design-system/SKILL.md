If creating visual artifacts (slides, mocks, throwaway prototypes, etc), copy assets out and create static HTML files for the user to view. If working on production code, you can copy assets and read the rules here to become an expert in designing with this brand.
If the user invokes this skill without any other guidance, ask them what they want to build or design, ask some questions, and act as an expert designer who outputs HTML artifacts _or_ production code, depending on the need.

**Hard rule for video and motion work:** every video must pin the GH brand footer for its full duration: logo on the left; TikTok, Instagram and `@ganjar_hadiatna` on the right, small regular-weight text, at the very bottom below the corner brackets (lifted 46px off the edge, 46px side padding), on a transparent bar (white text with a difference blend so it adapts to light and dark scenes). See `readme.md` > "Video and reels". Keep the closing CTA in the last scene content, separate from the footer.
