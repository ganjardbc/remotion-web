Satu skala spacing dipakai untuk gap, margin, dan padding di semua ukuran layar dan medium — tidak ada skala terpisah untuk "mobile" vs "desktop"; komponen menyesuaikan lewat berapa banyak step yang dipakai, bukan lewat angka baru.

Aturan
  • Gap antar elemen kecil (icon+label, tag di dalam baris) → --space-1/--space-2
  • Padding internal komponen kecil (tag, input) → --space-2–--space-3
  • Padding internal komponen besar (card, section) → --space-4–--space-5
  • Jarak antar section di halaman → --space-6 ke atas
