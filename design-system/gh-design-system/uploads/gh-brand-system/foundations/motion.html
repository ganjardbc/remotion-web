Tiga durasi, tiga easing — hover tombol di bawah buat ngerasain bedanya. Jangan tulis angka ms atau bezier manual di komponen baru, pakai token ini.

Durasi (hover buat coba)
Kapan pakai yang mana
  • --duration-fast — feedback state kecil: hover/active tombol, tag, link
  • --duration-base — default buat hampir semua transisi (border, background, shadow)
  • --duration-slow — perubahan besar: modal muncul, dropdown terbuka, progress bar mengisi
Easing
  • --easing-standard — default, dipakai hampir di semua tempat
  • --easing-decelerate — elemen masuk/muncul (modal, dropdown open) — mulai cepat, berhenti halus
  • --easing-accelerate — elemen keluar/hilang — mulai pelan, cepat di akhir
