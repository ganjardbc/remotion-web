Klik buat lihat komponen re-theme secara real-time — cuma toggle class .dark di body.

Tiga context berbeda di sistem ini, jangan ketuker: default (light surface) buat konten sehari-hari, .on-ground (biru brand) buat momen marketing, .dark (near-black netral) buat mode gelap interface app/web. .dark diaktifkan lewat class di <html> atau <body> — biasanya dari theme switcher, bukan otomatis dari OS.

Yang berubah vs yang tetap
  • Berubah: --color-surface/-alt/-text/-text-muted/-border, elevation (tint bukan shadow), warna link/outline (naik ke step 400), background alert & tag (jadi translucent)
  • Tetap sama: --color-accent, --color-accent-2, radius, spacing, motion, tipografi, brand mark gradient — identitas brand-nya gak berubah, cuma "ruangan"-nya yang gelap
